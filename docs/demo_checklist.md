# 最终演示与验收清单

## 启动

```powershell
cd D:\rengongzhineng\naive-bayes-spam-filter
python main.py
```

## 端到端演示

1. 普通邮件
   - 张三发送给李四。
   - 主题：项目会议
   - 正文：明天下午三点召开项目会议，请准时参加。
   - 验收：张三已发送可见，李四收件箱可见，判定方式为朴素贝叶斯，正常概率高于垃圾概率。

2. 固定规则垃圾邮件
   - 张三发送给李四。
   - 主题：活动通知
   - 正文：恭喜中奖，优惠活动开始，请及时领取。
   - 验收：李四垃圾回收站可见，判定方式为固定关键词规则，垃圾概率和正常概率显示为 `-`。

3. 贝叶斯垃圾邮件
   - 张三发送给李四。
   - 主题：礼品通知
   - 正文：限时领取礼品，请点击链接查看奖励。
   - 验收：李四垃圾回收站可见，判定方式为朴素贝叶斯，垃圾概率明显高，检测关键词可见。

4. 垃圾邮件纠错
   - 在李四垃圾回收站选择贝叶斯垃圾邮件。
   - 点击 `这不是垃圾邮件`。
   - 验收：邮件从垃圾回收站消失，并出现在收件箱。

5. 正常邮件纠错
   - 在李四收件箱选择一封邮件。
   - 点击 `标记为垃圾邮件`。
   - 验收：邮件从收件箱消失，并出现在垃圾回收站。

6. 反馈学习
   - 对一封贝叶斯邮件执行纠错。
   - 再发送相同或相似内容。
   - 验收：垃圾概率相对纠错前发生合理方向变化。一次反馈不要求直接翻转分类。

## GUI 细节检查

- 切换用户后邮件列表会刷新。
- 空收件箱、空垃圾箱不报错。
- 不选择邮件时详情区安全显示空状态。
- 写邮件时空主题可以发送，但主题和正文不能同时为空。
- 关闭写邮件窗口不会影响主窗口。
- 收件箱只显示 `标记为垃圾邮件` 按钮。
- 垃圾回收站只显示 `这不是垃圾邮件` 按钮。
- 已发送页面不显示纠错按钮。
- 连续发送多封邮件后数量正确。
- 窗口缩放后主要控件仍可用。
