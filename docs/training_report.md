# 训练记录与效果评估

## 1. 训练目标

本次训练的目标是增强系统对未命中固定关键词规则的垃圾邮件识别能力，尤其是以下类型：

- 不包含 `优惠`、`中奖`，不会被硬规则直接拦截。
- 包含 `点击`、`链接`、`领取`、`礼品`、`奖励`、`现金`、`促销` 等贝叶斯特征。
- 与正常教学通知存在部分相同特征，例如正常邮件中也可能出现 `点击链接` 或 `领取资料`。

训练保持正常邮件和垃圾邮件数量平衡，避免模型先验概率向某一类明显倾斜。

## 2. 训练方式

系统使用伯努利朴素贝叶斯模型。训练数据保存在 SQLite 的 `training_data` 表中。程序每次预测时都会读取最新训练数据，因此扩充训练样本后，后续预测会自动使用新模型。

本次训练采用两部分数据：

- 原始训练集：16 条，正常 8 条，垃圾 8 条。
- 补充训练集：36 条，正常 18 条，垃圾 18 条，来源标记为 `curated_training`。

训练后默认训练集合计：

| 类别 | 数量 |
| --- | ---: |
| 正常邮件 | 26 |
| 垃圾邮件 | 26 |
| 总计 | 52 |

## 5. 训练效果

| 指标 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 测试集样本数 | 10 | 10 |
| 分类正确数 | 9 | 10 |
| 准确率 | 90% | 100% |
| 正常邮件误判数 | 0 | 0 |
| 垃圾邮件漏判数 | 1 | 0 |

关键变化：

- `促销活动开始，请立即点击链接。` 训练前垃圾概率为 21.94%，低于 55% 阈值，被误判为正常邮件。
- 增加促销类垃圾训练样本后，同一测试邮件垃圾概率提升到 74.82%，能够被正确判定为垃圾邮件。
- 正常邮件中的 `点击链接`、`领取资料`、`活动礼品` 仍然保持为正常邮件，没有因为补强垃圾样本而整体误判。

## 6. 汇报结论

本次训练说明系统并不是依靠简单的 `if/else` 判定，而是会根据 `training_data` 中的有标签邮件重新统计概率。补充训练样本后，贝叶斯模型对不含硬规则词的促销类垃圾邮件识别能力明显增强。

由于当前模型只使用固定的 12 个关键词特征，因此训练效果主要体现在这些特征组合上。后续如果升级为自动分词和自动词汇表，系统可以进一步学习更多类型的垃圾邮件表达。
